# Orqanix benchmark evidence status

**Corrected September 20, 2026.** The September 18 comparison draft did not provide a reproducible record supporting its advertised performance, cost or readiness claims. Its numerical scorecard has been withdrawn and must not be used in board, customer or release materials.

Orqanix is a public preview. Its public and preview domains currently share the preview deployment. AxWise research, OMP workspace engineering and Jev evaluation are integrated to different degrees; a complete acceptance record from the released desktop installer is needed before describing the combined workflow as verified.

The public heartbeat now represents a dated HTTP health snapshot from one runner. It does not measure model workloads, desktop execution or uptime over a period. Scheduled GitHub Actions runs archive observations; they do not deploy the website snapshot. Missing, invalid and stale observations must be shown as unavailable or stale.

## Evidence required for a new comparison

Use real requests and retain the input, model and application versions, run date, output references, executed tests, elapsed time and provider usage. Compare equivalent tasks and disclose the number of runs and what the timer measures. Report caching savings only when cache use and billed usage are observed on that execution path.

Citations support source traceability; they cannot establish that every statement is correct. A signed receipt demonstrates properties of that receipt, not certification of the organization. Review decisions must distinguish passed, failed and not evaluated, and must be based on the relevant evidence and acceptance criteria.

No reproducible performance or cost comparison is currently published in this document. The immediate release milestone is a captured desktop journey from research through engineering and review, including failure behavior and restoration after restart.
