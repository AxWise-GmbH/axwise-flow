# Desktop harness revision

## Boundaries

Everyday information goes through a bounded, authenticated stateless endpoint, not an AxWise operation/worker/poll loop. AxWise retains PRDs, interviews, simulations and substantial evidence workflows. OMP remains local engineering, never an automatic search fallback. Existing auth, RBAC, billing and approval authority are unchanged.

JEV supplies advisory decisions over compact, identity-bound inputs. It cannot grant permissions, execute commands or declare work complete. Explicit Stop bypasses classification. Disabled, uncertain, stale or timed-out decisions preserve the incoming message in the queue. Mixed instructions remain intact until safe splitting is available.

## Implementation sequence and acceptance

1. Persist account/session-scoped follow-ups before delivery; keep steering on its original task; stable step IDs; separate model checklist claims from successful tool receipts. Test recovery, failed handoff, stale decision and account/session changes.
2. Add bounded authenticated JEV message disposition with model/rubric/input provenance. Test provider timeout, malformed output, disabled mode, mixed instructions and run binding.
3. Add stateless information transport and structured weather/currency adapters. Preserve terminal-answer and widget contracts. No durable operation or status polling for the new client path; no shell fallback.
4. Validate temporal discovery before presenting it as current. Missing or stale evidence produces an honest partial/no-verified-match response, not padded headlines. Semantic relevance/ranking may use JEV only after deterministic eligibility checks.
5. Benchmark fixed fixtures plus live representative queries: cold/warm latency, JEV on/off, source/date correctness, timeout behavior. Report sample count and p50/p95; do not confuse provider timings with desktop end-to-end timings.
6. Increment desktop version/build, sync connector provenance, build separate app, push only personal repositories, deploy preview services and update both website download entry points. No zero-downtime choreography is required for this pre-customer environment.

## Benchmark cases

- Current weather: Bremen, Riga, Kaunas; ambiguous city; provider outage; real provider time versus retrieval time.
- Latest local headlines; this-week events; parties within 150 km; short ranking/comparison. Reject old news, undated items and unsupported distance claims.
- Busy input: correction, independent follow-up, mixed correction/follow-up, explicit Stop, model timeout, stale run, restart during send.
- JEV off makes no TypeSafe request. OMP off leaves JEV available. No retrieval failure triggers shell, installation or engineering work.

## Open limitations to report

Do not promise exhaustive event coverage, classifier benchmark accuracy from a screenshot, or arbitrary semantic plan rewriting. Cached current data retains its source timestamp. Model checklist completion alone is not an execution receipt. Remaining unimplemented items must be listed in the release handoff.
