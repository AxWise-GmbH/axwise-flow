Strategic Monorepo Rationalization

Orqanix Lean Architecture Blueprint

Detailed division of responsibilities: what belongs strictly in Orqaly Cloud, what should be Omitted / Deleted to eliminate technical debt, and what is Delegated to Goose Desktop.

🛡️ 1. KEEP ON ORQALY (The Lean Cloud Core)
High-value, multi-tenant cloud capabilities that provide identity, audit, durable queues, and cognitive interfaces.
Multi-Tenant RBAC & PostgreSQL RLS
Core Keep
Clerk authentication, tenant identity resolution, JIT provisioning, and strict Row-Level Security (SET LOCAL orqaly.tenant_id = $1) across all tenant tables.
apps/orqaly/database/workflow-v2/migrations/001-025
AxWise <-> Orqaly Cognitive Contracts
Core Keep
Wire contract (axwise.operation.v2), RFC 8785 canonical JSON hashing, Idempotency-Key handling, and Cloud Run IAM service authentication (GoogleAuth).
apps/orqaly/shared/workflow-v2/contracts.js & backend/domain
Desktop Gateway & Model Proxy
Core Keep
Authenticated /desktop/v1 endpoints proxying Goose completions to Gemini 3.8 Flash (1M context), injecting run context and rate limiting without client keys.
apps/orqaly/server/workflow-v2/goose-provider-http.js
Durable Goals Timeline & Artifact Vault
Core Keep
The 10-stage execution state machine (scope, plan, research, draft, review, final_markdown), transactional outbox (SKIP LOCKED), and immutable GCS artifact exports.
apps/orqaly/server/workflow-v2/worker-engine.js
Real-Time Assistant Turn Streaming (SSE)
Core Keep
Server-Sent Events streaming (/v2/assistant/threads/:id/events), multi-turn conversational memory, retry/resume lineage, and human-in-the-loop approvals.
apps/orqaly/server/workflow-v2/assistant-service.js
Subscriptions, Quotas & Token Accounting
Core Keep
Hourly tenant execution limits, plan quotas, LLM token metrics (input/output/cost in micros), and Clerk/Stripe subscription status enforcement.
apps/orqaly/server/workflow-v2/postgres-repository.js
🗑️ 2. OMIT / DELETE (Cut Technical Debt)
Legacy code, mock catalogs, abandoned Vercel handlers, and unmounted stubs that create maintenance overhead.
40+ Legacy Vercel Serverless Handlers
Delete
Unmounted historical handlers in apps/orqaly/api/: communicator real-time rooms, ElevenLabs audio TTS/transcribe, pitch deck investor CRM, and legacy PIN logins.
apps/orqaly/api/* & apps/orqaly/lib/api-handlers/*
Fake Static Tool Catalog (libraryMcpCatalog.js)
Purge
Static JSON file with >80% non-executable tools (Carrd, Framer, Slidev, Marp). Pretentious metadata without actual MCP servers.
apps/orqaly/shared/libraryMcpCatalog.js
Naive Embedding Fallback (hashEmbedding)
Replace
Crude word-modulo hash used in memory-manager.js when HuggingFace is unreachable. Destroys vector search semantic quality. Replace with Gemini Embeddings.
apps/orqaly/lib/workflow-engine/memory-manager.js
Fragmented Legacy Concilium Handlers
Consolidate
Multi-agent consensus code split across legacy Supabase tables, snake_case wrappers, and cron loops. Consolidate cleanly into agentic-control-plane.
apps/orqaly/lib/concilium-handlers/
Direct Supabase Client Dependencies
Purge
Legacy client-side Supabase tokens and table clients. Already blocked by gcpModuleBoundaryGuard; should be physically deleted from source tree.
apps/orqaly/src/supabase.js & related shims
💻 3. DELEGATE TO GOOSE (Local Operator)
Capabilities that inherently belong on the user's laptop with native OS access, zero latency, and local developer toolchains.
Native Goose Engineering Tools
Goose Exclusive
Native AST inspection, local LSP queries, SHA-guarded edits and approved test execution within the Goose conversation loop. Availability depends on the installed native extension.
orqaly-goose: crates/goose/src/agents/platform_extensions/native_engineering/
Native OS & UI Automation (Peekaboo)
Goose Exclusive
macOS Accessibility APIs, multi-window screen capture, button clicking, typing, and local system dialog control. Impossible inside headless cloud containers.
Goose Computercontroller extension
Local Shell, Compilers & Git Worktrees
Goose Exclusive
Direct execution of cargo, npm, pytest, git branch creation, and local script execution within the user's explicit authorization perimeter.
Goose Developer extension (bash / shell)
Local Document Tooling (Word / PDF / Excel)
Goose Exclusive
Direct filesystem manipulation of .docx, .xlsx, and .pdf documents via Python/Node office tool extensions without uploading sensitive enterprise files to cloud.
Goose docxTool, pdfTool, xlsxTool
Private Session Memory (Chatrecall)
Goose Exclusive
Fast, local session transcripts and conversational recall stored safely on the user's machine (~/.goose) requiring zero cloud DB roundtrips.
Goose Chatrecall extension
