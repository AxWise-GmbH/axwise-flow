SLIDE 5: How It Works.
Orqaly handles orchestration in four simple steps:
1. Define: User describes the outcome and sets a budget limit in USD.
2. Plan: The Consilium (multi-agent council) decomposes the goal into parallel tasks.
3. Execute: Agents execute tasks in sandboxed containers. Watch cost burn in real time.
4. Deliver: Outputs are compiled into a review queue with full audit trails.

SLIDE 9: BPMN Architecture and Data Flow.
Orqaly and AxWise run a unified data flow:
1. User Layer receives messages from Telegram, Slack, Teams, Email, or Web Portal.
2. Message Router detects intent, and maps to the appropriate Digital Twin in the Twin Registry.
3. The Active Twin checks the RBAC gateway. If denied, it writes to the Audit Log. If approved, the Data Retriever performs similarity search on Google Drive, Slack, Figma, Notion, Jira, or private databases.
4. The Response Builder compiles the final formatted output and delivers it to the user.
